Acesso online em vários dispositivos

Para sincronizar entre computador e celular, o CRM precisa de uma base de dados online e autenticação. Esta versão não envia seus dados para a internet e não está sincronizada.

Opção gratuita sugerida: publicar a interface no GitHub Pages e usar Supabase para autenticação e banco de dados, dentro dos limites gratuitos dos serviços. É necessária uma configuração técnica e regras de segurança antes de guardar dados comerciais reais.

Status: modo local • sincronização em nuvem não configurada

Não cole chaves secretas ou credenciais neste arquivo público. Não guarde balanços, documentos pessoais ou informações financeiras sensíveis sem controles de acesso adequados.

Migração segura

  1. Exporte a carteira em CSV para backup.
  2. Crie um projeto Supabase e configure login.
  3. Crie tabelas de empresas e histórico com regras de acesso por usuário.
  4. Conecte a aplicação com variáveis públicas adequadas e políticas de segurança.
  5. Teste sincronização e recuperação antes de inserir sua carteira real.

Este painel é um guia; ele não configura automaticamente uma conta externa nem ativa sincronização.
